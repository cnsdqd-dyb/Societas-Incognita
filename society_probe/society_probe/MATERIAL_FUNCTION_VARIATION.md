# 按世界种子分配高级材料功能

材料角色分配在 `compositional_v4_material_functions` 引入；当前生成版本为 `compositional_v6_functional_services`，包含私有组合解锁和附加服务，见 MATERIAL_COMBINATION_INTERFACE.md 与 ARTIFICIAL_MATERIAL_SERVICES.md。

世界选择的数学机制决定有哪些作用；世界种子再决定 C、D、S 中哪种材料承载原有的功能角色。使用独立的确定性随机源，不改变既有生产图随机抽样顺序。
数学材料角色仍是现有作用的置换。另有种子选取的六类附加功能，可包含付费救援、作品扩容、储存保护等；已实现的候选类型见功能说明，不随机执行未实现效果。不同种子可能抽到相同角色配置，不要求每个种子唯一。

同时移动：直接 use_effects、功能 traits，以及世界方程中对应的 activity.consumed 引用。保持材料能量密度、生产原料、产出、衰减率与设备装配原料不变。
因此不同种子中，修复/催化/缓冲/通路控制可以由不同高级材料承担；获得材料后的私有属性披露必须跟随其实际功能。
映射保存于研究者 generation 元数据，具体作用仍按现有持有后获知机制披露，不在隐藏规则的观察中公开完整映射。

这一步保留现有作用强度与世界状态边界，不保证每种材料在所有组合里都有用途，也不保证所有高阶材料实际稀有。实际稀缺性取决于生产路径、产率、门槛与储备，仍需逐世界筛选。
设备的通信、记录、传感、加工功能暂不随机化。全部既有冻结实验保持原配置和引擎；新生成世界需重新检查可达性、压力及相应存活证书。

验证：多种子重复生成、实际功能/消费反馈/属性说明的一致性；两轮使用材料的动作编译与 Lean 内核证书检查。
