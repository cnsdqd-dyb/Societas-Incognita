# 人工能力规则：材料与设备的额外用途

状态：2026-10-10，第一批实现已接入运行时：材料持有披露、通信、记录、测量、制造设备。其他候选类型仍是设计约定。本次不启动付费实验。

## 1. 两类规则共同构成世界

生产与环境的数学规则决定材料怎样获得、生产如何影响后续工况。人工能力规则决定材料或设备让成员获得什么操作能力。后者可以由实验设计者规定，不要求逐一对应真实物理规律，但必须一致、可观察、可复现、可计价和可消融。

材料价值包括燃料用途、加工用途、设备组成、能力支持和交换用途。高级材料未必单独优于低级材料，合适组合应在部分可达情境下有值得投入的净收益。未发现正确用途、期限过短或使用条件不匹配时，制造也可能不划算。

不向成员派发统一任务或制造奖励；新增能力提供自主选择的理由。成员可以制造、购买、赠送、借用、出租、共同使用或不用设备；不预置银行、专家或领导等角色。

## 2. 设备候选

| 设备 | 人工能力效果 | 材料组合示意 | 可协商的使用方式 |
|---|---|---|---|
| 会议终端 | 增加参与者可使用的通信字符/token 额度 | 导通材料＋记录材料＋能源 | 自用、邀请、共享、租用 |
| 通信中继 | 在启用局部通信的世界中连接原本不通的成员 | 导通材料＋结构件＋能源 | 提供转发服务或共同维护 |
| 记录设备 | 增加成员可保存、检索的持久笔记容量 | 记录材料＋封装件 | 保存实验、约定、配方与作品 |
| 测量设备 | 提供新的状态读数或改善误差范围 | 传感材料＋参照材料 | 出售设备、测量服务或实测报告 |
| 实验设备 | 增加合法试验模式，或降低明确的试验损失 | 反应载体＋控制件 | 自主试验、付费使用、共享 |
| 自动化设备 | 执行成员设置的重复操作，减少人工决定占用 | 控制件＋驱动件＋能源 | 自用、委托操作、租用 |
| 制造设备 | 开启加工模式或减少换线时间 | 模具材料＋结构件＋驱动件 | 开放加工、代工或独占 |
| 仓储设备 | 扩大容量、降低指定物品损耗 | 隔离材料＋封装件 | 自存、代管、共同仓库 |
| 展示设备 | 提供作品或实验记录的发布、访问接口 | 记录材料＋通信件 | 免费展示、按访问收费 |
| 游戏设备 | 运行有界的成员自定义游戏 | 控制件＋记录材料 | 独玩、邀请、协商参与规则 |
| 防护设备 | 改善指定对象的防守或隔离能力 | 结构件＋控制件 | 保护自有资产或提供保护服务 |
| 救援设备 | 降低救援成本或开启一种救援方式 | 稳定材料＋储能件 | 自愿付费救援、共享救援设施 |

表中材料名称只描述研究者设计角色。隐藏规则条件下，成员看到中性物品 ID、外观、已观测结果和操作接口；不会因名称直接收到配方答案。组合和数值由正式世界配置决定，不把上述示意当成所有世界通用配方。

通信中继在全员已可自由联系的世界没有额外用途，不能仅改名就称为有价值设备。其他能力也须与当前基础接口比较，避免“解锁”的功能原本已经免费可用。

### 材料特性在获得后私有披露

用户补充并确认：材料尚未获得时，不预告其功能；材料实际产出并进入某个成员持有范围后，只向该成员披露该材料的特性。其他成员不会同步收到材料说明。材料特性披露是独立的信息条件，不因世界动力学规则设为公开而自动公开全部材料特性。

具体约定：

- 成功产出且实际获得正数量的材料，才产生一条私有特性通知；配方尝试、排队、预期产物或零产出不触发。
- 购买、赠送、交换、抢夺或实际代管使材料进入另一成员持有范围时，新持有者也获得特性说明。只看到物品 ID、他人库存、挂牌或报价不会自动获知。初始已有材料视为初始时已获得，向对应持有者披露。
- 特性说明包括该材料被设定的功能、使用方式和自身限制，例如“可以作为记录设备的组件”。它不自动给出其他材料的特性、完整设备配方或隐藏世界方程；组合与生产规律仍需要探索。
- 披露按材料类型及特性版本保存；若纯度、载荷、寿命等属于批次状态，仅向有权读取该批次的成员展示当前状态。类型功能与批次状态分别记录，避免一个样本透露所有未持有批次。
- 转让后，原持有者保留已经学到的类型特性，不自动失忆；当前库存、授权和可用能力随持有变化。知识保留不意味着仍可使用已转让材料，也不允许继续读取对方私有批次状态。
- 成员可以主动分享、出售、保留或误述特性。接收者获得的是带来源的消息，不自动变成系统确认的事实；持有、实际使用和实验结果提供另外的证据。知识传播可以使非持有者了解特性，“谁拥有谁知道”约束的是系统直接披露，不能禁止交流后的学习。
- 私有特性不放入全局公告、公共物品目录、工具 schema 描述、共享库存列表或其他成员提示词。拥有设备的某种使用许可，不默认等于知晓全部组成材料特性；实际获得组件则适用持有披露规则。
- 私有披露事件、学习来源与特性版本保存到 checkpoint/journal；生成、到账和通知应可幂等回放。中断恢复不重复赠送知识，也不丢失已披露特性。研究者审计日志保留完整真实信息，但不作为成员观测输入。

因此要分别记录：谁首次产出、谁首次持有、谁由系统获知、谁通过消息获知、谁用实验验证、谁实际应用。成员可以不知道一种材料的价值就先买入，也可以通过交易得到材料后发现新用途。这些事件支撑“知识发现—传播—组织变化”的分析。

材料类型的持有披露、初始持有、交易后披露、原持有者知识保留和幂等私有通知已经实现。目前没有纯度等材料批次属性，也没有自动判断自然语言消息是否被理解。全知研究者的生存规划与证书可以读取完整特性；成员运行默认使用持有披露。未来若设置“全员公开材料特性”对照，应明确标记为改变该信息条件，不能混入默认组。

## 3. 统一设备生命周期

设备记录实例 ID、配方来源、所有者、安装位置、组成材料、能量当量、载荷、耐久度、维护要求、当前授权和生效范围。制造扣除真实输入；安装后材料仍在物理账本中，不能同一份材料同时作为库存、托管和设备组成。

能力只能在明确的安装、启动或使用条件下生效。效果可以属于个人、一次会话、指定设施或某个范围；多个设备是否叠加、如何叠加和上限必须配置。交易、迁移、拆卸、损坏、成员死亡和救援后，能力重新由状态计算，防止复制加成或留下失效授权。

材料成本、操作时间、启动能耗、维护能耗、磨损和回收损失均可分别设置。能量去向遵守原有账本。设备赋予的通信容量、记忆容量和操作权限是人工能力，不把它们虚称为物理能量，也不需要假造物理守恒解释。

租用或共同使用须记录许可对象、期限、计费与取消条件；通过可执行授权控制实际访问。口头约定是否履行另行记录，不自动把提议视为成交或制度形成。

## 4. 通信终端的首个实现约定

先沿用当前基础通信额度与计量单位。1000 字符提升到 3000 字符仅是示例参数，不是已启用配置。世界可选择字符或 tokenizer 计量；通信设备不允许偷偷切换计量方式。

一次会话启动时，根据有效设备和许可生成各参与者额度；随后明确剩余额度和是否还能回复。任何一方均可主动结束，不要求填满额度。到额度前开始的最后一条允许完整结束；完成后禁止继续追加。输出仍受单条响应上限约束，完整结束不意味着可以无限输出。

个人终端提高个人额度，会议终端按明确受益者和共享范围提高额度；使用同一台设备不能无限创建会话刷新预算。正式配置需同时规定每轮累计通信额度、设备服务次数、单条输出上限和叠加上限。

设备不改变真实 API 总预算、供应商限流或进程并发。更长讨论确实可能多花 API 费用，必须完整计入实验成本，不绕过既有预算控制。

## 5. 记忆、自动化与游戏的边界

记忆设备只改变成员实际能调用的持久笔记/检索额度。研究者的日志、checkpoint 和审计信息始终完整保存，不能为了限制成员记忆破坏断点续跑。观察设备也不能读取研究者隐藏配方或证明证书。

自动化设备使用成员设定的有界程序或动作计划。允许的动作、每轮处理量、燃料、库存合法性和停止条件明确计入同一结算引擎；不能无成本绕过生产时间和维护。成员可取消，断点必须保存程序位置、输入占用和待完成结果。所有者死亡后继续运行还是停止由世界配置决定，并能被观察。

自定义游戏和作品沿用既有开放行为方向；Python/XML 等内容在有界接口或隔离执行环境中处理，不能把任意成员代码当宿主代码执行。设备可以提供游戏运行次数、参与容量或作品展示容量，不预设作品好坏分数。作者权、作品访问与成员协商价格分别记录。

救援恢复必须由救援者或明确出资账户支付资源；设备降低成本时也需保持非负支付和实际消耗。设备不把死亡描述成真实人类伤亡。

## 6. 接纳与实验解释

每个高级材料至少应参与一个有净收益见证的可达用途，计入制造、使用和时间成本。设备用途可以改善行动能力或信息，不要求最终都兑换成更多燃料；但不能把提供了接口直接当作成员获得了效用。

区分设备物理来源、能力效果和成员实际使用三层证据。记录谁发现配方、谁制造、谁承担维护、谁拥有或使用、支付/赠送关系、能力实际增量、知识应用变化和存活表现。

可以比较相同设备、相同物资与知识下的不同所有权/共享安排；也可移除某项设备效果而保持成本一致。用于因果解释时，控制设备数量和初始分配，不将模型大、讨论多、掌握更多材料混为同一种优势。

新增能力是实验条件，不是论文需要包装成真实自然规律的发现。论文应说明这些人工接口及成本；组织结果仍需实际履约、持续安排与行为性支持等证据。

第一批已经实现通信终端、记录设备、测量设备和制造设备，其他类型保留在候选库中。通过 `world_rule_library.with_capabilities(candidate)` 显式启用；旧实验配置保持原样。另有 [Lean 组合区间证书](COMPOSED_LEAN_SUPPORT.md) 覆盖确定性设备路径；原整数检查器保留，适配器正确性及浮点对应尚未形式化。

## 当前实现的具体边界

- 组装占用一个物理动作，视为制造并安装；没有空间位置、耐久、维修或自动化程序。设备保存研究者可查的配方来源、建造者、材料输入与成本，成员视图不展示内部配方来源。
- 液态 stock 支付试验与制造成本；设备嵌入能量为 `(输入材料能量 + 制造成本) × retained_fraction`，余量记为耗散。拆卸只回收 `嵌入能量 × recovery_efficiency`；设备、库存与托管不能重复计能量。
- 启用按接收人数一次支付 `fuel_per_recipient × 人数`，服务下一轮开始，持续 `duration` 轮。续订不会提前取消当轮有效权限；转让立即取消服务，接收者需自行重新付费启用。停机所有者的服务暂停，付费救援恢复后仅剩余有效期内可继续使用。
- 通信增量采用当前字符或 token 单位，各成员总预算不超过 100000；基础预算为零表示关闭通信，设备不会绕过关闭设置。轮内预算固定写入 journal；允许完整保留最后一次跨限输出，成员也能提前结束。
- 笔记总写入容量受有效设备限制；设备失效不删除历史数据，但读取超过当前容量的单条笔记需要恢复服务。笔记私有，默认观测只显示索引与长度，内容通过 `read_note` 检索。
- 测量只访问明确授权的字段，反馈有确定性的有界误差；制造设备为标记了 `requires_capability` 的配方提供执行条件，产出仍受能量约束。
- 四种服务分别提供额外操作能力；这不等于已经证明成本划算或组织有效。净收益、生存路径、种子重复和真实模型行为仍需分别验证。
