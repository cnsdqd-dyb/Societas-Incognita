# 完整算子区间可靠性：2026-10-10 后续

## 精确命题

**PROVABLE AS STATED**。任取算子 `op`、输入区间 `a,b`、结果区间 `r`、有理数 `x,y`，若

1. `check ⟨op,a,b,r⟩ = true`；
2. `InBox a x` 且 `InBox b y`（含正分母要求），

则 `InBox r (evalOp op x y)`。

统一定理为 `interval_advanced.lean` 中的 **`check_sound`**。它覆盖现有检查器全部 13 类算子：常量、加减乘除、取负、最小/最大、取整、严格/非严格比较、相等、真假转换。它按算子分类，调用各算子的通用定理，不依赖某条轨迹的具体数值。

## 本轮补齐的证明

- **除法**：先证明同号非零有理数的倒数反序，再把合法除法区间转成乘法区间，复用四角点乘法可靠性。除数为正或负都覆盖；包含零、端点为零的区间不能通过检查。
- **取整**：通过整数欧几里得除法性质证明有理数取整的单调性；端点取整一致，推出整个区间取整结果一致。负分子同样覆盖。
- **比较**：以有理数序的传递性证明整个输入区间上的比较结果。无法确定的重叠区间拒绝检查通过。
- **相等**：使用交叉乘积定义数值相等，覆盖不同的分数表示；不依赖分子、分母结构相同。
- **真假转换**：零输出为假，严格位于零的一侧输出为真；跨零且非单点的区间不能被误当成确定真假。

此前的七类运算证明仍在 `interval_soundness.lean`，本轮的新增算子与统一定理位于 `interval_advanced.lean`。

## 保留的证明边界

“完整算子可靠性”只指现有 `Op` 类型中的 13 类原语，不表示完整世界模拟器证明。尚缺：

1. **运算图连接**：每个节点的输入确实是对应上游节点输出；常量和状态输入确实来自被声明的世界初态。
2. **世界转移连接**：物理规则、支付、设备权限、生产与生命状态等正确展开成运算图。
3. **前端/运行时连接**：JSON 规范化的正确性和 Python 浮点执行与有理数学语义的对应。
4. **扩展机制**：随机扰动下的鲁棒策略及交易托管、抢夺、防守、救援等。

伴随证明没有更改既有主证书及其哈希；主实验准入尚未使用一个端到端语义定理。下一步是带节点依赖的运算图检查器与包含关系归纳证明。
