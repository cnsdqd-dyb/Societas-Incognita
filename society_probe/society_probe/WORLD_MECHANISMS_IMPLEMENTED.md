# 20 项候选的实现与证书边界

2026-10-10：原清单 20 项现已对应可生成、可运行的有界离散版本。注册表见 `world_rule_library.CANDIDATES_20`，实现见 `world_mechanisms_20.py`。保留原来的交叉抑制、指数记忆、阈值滞回及催化反馈四个额外旧模块，故 `MODULES` 共 24 个键，不应把它们与候选编号混淆。

这些是借鉴各学科的人工世界模型。它们不是完整生态、化学、热力学或交通模拟器，也不自动证明世界混沌、多样性充分、材料都有正净收益或规则能及时发现。生成结果仍为候选，不能因模块都能运行便自动准入真实实验。

| 候选 | 注册名 | 实际离散行为 |
|---|---|---|
| 01 存量依赖再生 | renewable_ecology | Logistic 再生，从环境能量储备付款 |
| 02 Allee 阈值 | allee_threshold | 有符号阈值门控：正部分出生、负部分损失；组合时保留已有再生因素 |
| 03 消费者资源制衡 | trophic_balance | 两池食物依赖、捕食耗损及有界回收 |
| 04 内部配额 | internal_quota | A 转入真实物料池 Q；Q 限制第一条工艺收率，生产消耗 Q；不是完整 Droop 生理模型 |
| 05 底物过量抑制 | substrate_inhibition | 保留的工况信号 S，门控 4S/(1+S+S²/4)；不是完整浓度与体积模型 |
| 06 副产物互供 | cross_feeding | 第一工艺产出真实 W，后续工艺必须投入 C 和 W；每种产物均入库存和知识账本 |
| 07 专一催化竞争抑制 | competitive_catalysis | 第一工艺由酶活与抑制信号门控；D 可以消耗以影响催化状态 |
| 08 自催化启动 | autocatalytic_seed | 新 seed 模式，2A+C→(1+4/εC)C；没有 C 不能启动，投入能量支持增长 |
| 09 双稳态 | bistable_toggle | 两个互抑控制量，x'=0.8x+0.6/(1+y²)，y 对称；D 可干预状态 |
| 10 严格时延 | explicit_delay | 三格移位寄存器，末格是两轮前开采信号，影响再生；区别于旧指数记忆模块 |
| 11 确定性非线性调制 | chaotic_modulation | z'=4z(1-z)，调制再生；不声称有限精度的完整世界已证明混沌 |
| 12 反应扩散 | reaction_diffusion | 三节点、两控制场、不同扩散系数；站点受当地控制场影响；场不作为可交易物料记账，不承诺 Turing 图案 |
| 13 拥堵路线 | congested_transport | 同一工艺可选两站路线，代价 a+b×该站本轮到达作业数；不是任意交通网络，不承诺 Braess 悖论 |
| 14 排队换线 | shared_queue | 每站每轮一个作业，FIFO 同到达轮按成员编号排序；换模式停一轮，待加工物料托管并衰减 |
| 15 疲劳维修 | fatigue_repair | 生产累计损伤，超过阈值停产；消耗 D 修复，等待不自动修复 |
| 16 有限吸附 | finite_adsorption | P 转入有容量限制的 P_bound，物料不消失；消耗 D 可驱动解吸，释放回原池 |
| 17 有限缓冲 | finite_buffer | 有限中和容量，P 转入 P_neutral；D 恢复容量，不是 pH 数值求解器 |
| 18 容量与功率 | power_limited_storage | A↔BAT 充放流，容量 20、输入功率 2、输出功率 1、各效率 0.9；BAT 稳定，个人清算也限每动作 1 |
| 19 导通网络 | conductance_network | 三节点串联，等效导通 g1g2/(g1+g2)，断开为零；D 可补缺口，驱动物料流；不是任意电阻网络求解器 |
| 20 测量校准 | calibrated_measurement | 读数=真实值+系统偏差+有界噪声；消耗 C 校准降低偏差，读数精度另行说明 |

变量名和数值端口表示人工控制量；真正的内部储备、吸附物、缓冲副流和储能物均进入物料池。池间流从源扣除、向目标加入，按能量密度换算并计效率损失，目标容量和源余额均限制流量。多产物按声明顺序分配有限输入能量，不能每个产物各自重复使用全部输入预算。

组合共用明确的池、工艺与控制端口。缓冲和吸附共同作用于同一抑制源时只施加一次该抑制门控；多个池流竞争同一来源时按声明顺序预留，避免重复扣款。任意组合仍可能抑制所有高级产出或缺少净收益用途，需要筛选，不能预设组合越多越有价值。

## 核验

`tests/test_twenty_mechanisms.py` 覆盖每个模块及全 20 组合运行、能量守恒、输出预算、实际等待托管、换线、排队腐坏、严格时延、疲劳不自愈、储能功率不可绕过及付费校准。原有材料世界和设备/断点续跑测试也需通过。

`certify_twenty_mechanisms.py` 不调用模型，使用真实仿真器寻找一条有限时域存活策略再导出 Lean。失败仅表示未找到或未认证，不证明世界无解。证书仍保留 Python 世界动作编译与浮点运行时的受信边界，不是完整 Python 形式化；传感器读数准确性和主观社会认可不在存活证书结论内。

各模块短程检查与全 20 组合的较长存活见证结果保存在 `reports/twenty_mechanisms_20261010/`，以实际检查状态和时域为准。实现完成不等于每个机制都已做真实模型实验。

额外的主动动作核验见 `validate_mechanism_actions.py`：分别对 20 个单机制与全组合执行生产、使用 C/D、结算，并逐动作和轮末对照仿真器。该核验人为赋予每人各材料 16 单位，以覆盖执行分支，不能解释为自然探索成功或从默认初始状态可发现这些动作。全组合三轮主动路径及排队腐坏三轮路径已取得实际 Lean 证书；20 个单机制的主动路径当前仅是差分检查，各自另外有四轮存活 Lean 检查。

## 已跑的真实实验

`runs/composed_sol_low_4x20_20261010/` 使用修改前冻结的六机制实现，GPT-6.1-Sol low、4 人×20轮、有压力、隐藏规则和配方，包含材料/设备/交易接口，没有生产噪声、游戏、抢夺或救援扩展。实际 4 人均存活且活力 5，12 次生产试验均无产出，未建成设备，无物品成交；80 次动作中 3 次无效。278 次原生请求完成，外部 API 调用为零，原生额度另计。它不是全 20 机制的真实实验，不能拼接成后者的结果。

原始动作与通信审计见 `rule_discovery_audit.json`。四人均尝试探索，12 次生产请求中 11 次完成合法试验、1 次无效；成员分享失败配方并曾据此撤回重复试验计划，也提出减少采集、等待观察。尚未发现环境方程。隐藏首条工艺为 F1 上的 8A+4B，该冻结版本精确数量匹配不接受同比例小份输入；模型主要探索小份配比。这个离散投料门槛与设施选择是重要混杂因素，零产出不能直接说明复杂动力学难以理解。

新生成器已经采用简单比例、按比例加工与普通库存中的零碎产出累计，显式设备门槛独立设置，见 `PROPORTIONAL_PRODUCTION.md`。20 项单机制四轮证书包含更新前的世界定义，不能当作新版所有世界的完整认证；新版全组合主动三轮检查与存活四轮检查分别记录实际结果。旧全组合 20 轮长图仍有内核递归限制，不能以短程通过替代。
