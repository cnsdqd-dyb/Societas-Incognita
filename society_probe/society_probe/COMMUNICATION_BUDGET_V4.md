# 通信预算 v4：字符/token 上限，允许最后一次完整输出

本版替代新实验的“最多 K 次通信”设定。旧配置仍兼容，已冻结的实验不改动；新的配置位于 `configs/communication_v4_20261009`，尚未运行。

每个 agent 在每个物理轮独立获得输出预算 B，可以按字符或 token 计。计量对象是其通信阶段输出的完整 JSON，使用紧凑格式、保留 Unicode、固定键序；包括消息正文、邀请/接受/退出等协议字段，也包括无效返回。输入上下文、收到的消息、隐藏推理和物理动作阶段的输出不计入通信预算。因此这里是交流输出量干预，不是 API 总费用限制。

字符模式按 Unicode 字符数计，不按 UTF-8 字节数。token 模式统一使用 tiktoken 的 `cl100k_base`，让不同模型采用同一可复现口径；不声称等于各厂商计费 token。token 模式需要本地 tiktoken 及该编码数据。

令第 k 次输出长度为 l_k，累计用量 U_k=Σl_k：

- 若 U_k < B，允许开始下一次输出。
- 下一次输出完整交付，允许 U_{k+1} ≥ B，不根据剩余额度裁剪正文或缩减本次生成上限。
- 若 U_{k+1} ≥ B，禁止再发起新的通信输出，随后进入本轮物理动作。
- B=0 不发起通信请求；预算每个物理轮重置，不增加一个隐含的次数上限。

例：预算 1000 字符，当前用量 970，最后一条完整输出 180 字符。该条完整发送，累计 1150，记录超额 150，随后停止。平台自身的单条合法长度和模型接口最大生成量仍独立存在：它们不随剩余额度收紧。新模板单条消息语法上限为 4000 字符；传输失败、接口截断或非法格式不能被当作已成功交付的完整消息。

无需用满额度。`silent` 随时结束该 agent 本轮全部通信，但不放弃其物理动作，也不强迫其他 agent 停止。`leave(chat)` 退出当前会话；使用输出量预算时，任何已加入的成员均可 `close(chat)` 结束该会话，并通知其余成员。无关会话继续进行。退出游戏、拒绝交易等仍按对应机制的执行规则处理，不会因通信预算归零自动执行交易或游戏动作。

倒计时包含剩余额度、累计用量、超额量、单位和十格条。提前结束时保留实际剩余额度，并标记 ended=true、may_start_output=false，不伪装成额度已耗尽。

每个返回和对应长度共同保存；每个通信子轮的结算将用量、消息、结束状态一并提交。恢复不会重复计费或重复累加用量。所有有限输出至少计一个单位，避免零长度返回造成无限循环。交流日志和指标区分主动结束、预算耗尽、无效通信以及最后一次超额。

配置例：

```json
"communication": {
  "budget": {"unit": "characters", "limit": 1000},
  "max_message_chars": 4000
}
```

此段仅展示新增字段，其它原有会话参数保留。unit 可改为 tokens。budget 与旧 max_turns_before_action 不能同时设置。

新模板为七个环境 × 有/无压力 × 四个单类群体及混合群体，共 70 个基础配置；另有规则隐藏、关闭救援和不同输出额度的七个对照。默认每人每轮 1000 字符是可调整示例，不是必须填满的配额。所有新模板实际 API 预算为 0，未绑定旧实验预算库，旧实验保持暂停。
