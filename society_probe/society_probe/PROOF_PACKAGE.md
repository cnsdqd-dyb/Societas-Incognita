## Claim

给定一个确定性 mini-world 世界定义、配置初态和固定的 $N$ 人、$T$ 轮联合动作表，编译器生成有限区间转移约束证书。Lean 核验算以下封闭命题：所有输出区间包含相应算术运算的结果范围，所选条件与取整分支的守卫成立，全部 $NT$ 个轮末活性区间的下端点为正。

若世界定义到约束图的适配器忠实于下述数学语义，则这些事实推出：该动作表在这个数学模型中是全员存活的有限策略见证。它不推出智能体能够发现策略、策略最短、资源最优、公平或组织得到认可。

## Status

**PROVABLE AFTER WEAKENING / EXTRA ASSUMPTION**。

Lean 已证明的是生成约束程序的封闭命题。将它提升为对原始 JSON 世界或 Python 解释器的端到端定理，还依赖世界适配器的正确性；该适配器和 IEEE-754 等价性没有在 Lean 中形式化。仿真轨迹的独立交叉校验提供测试证据，不能替代这个缺失的形式化证明。

## Assumptions

- 世界无生产/采集随机扰动；执行顺序是配置种子生成并固定下来的动作表顺序。
- 规则常量按 JSON 十进制表示解释为有理数。支持有界加减乘除、整数幂、最小/最大、裁剪、比较和逻辑运算；不含 `exp`。
- 除法区间不包含零；条件区间能确定真假；产量区间的下、上端点取整相同。否则编译器拒绝证书。
- 策略只使用当前覆盖的物理动作：等待、检查、采集、清算、赠送/能量转移、试验、材料使用，以及第一批设备动作。交易托管、抢夺、防守、救援与其他社会扩展不在本证书范围。
- 所有者、设备权限、寿命、配方匹配、笔记长度和动作表结构由适配器按固定配置展开；这些离散结构的编译正确性属于上述适配器假设。
- 基础数学池状态满足 $0\le p_k\le C_k$，再生请求非负，分配比例属于 $[0,1]$。池边界裁剪利用这个不变量，不改变满足不变量的实数转移。
- 测量动作的权限得到检查，但具体随机读数的准确度没有进入生存证明；该读数不改变物理状态。

## Notation

$I=[l,u]$ 是包含真实数学值的闭区间，$l,u\in\mathbb Q$。有理数在 Lean 中表示为整数分子和正整数分母；每个约束都检查分母正性和 $l\le u$。

$S_t$ 表示第 $t$ 轮数学状态，$\mathcal I_t$ 表示其分量区间。$a_t$ 是该轮固定联合动作。$h_{i,t}$ 表示成员 $i$ 的活性。$\varepsilon=10^{-9}$ 是运行规则中支付与产量取整使用的显式容差；区间向外取整的尺度为 $10^{-18}$。二者作用不同。

## Proof Strategy

按区间算术局部包含关系，沿约束图及物理轮次作归纳。Python 计算候选端点，Lean 重新检查整数交叉乘法、边界和守卫，不信任 Python 的“通过”标志。相同数值或相同封闭约束可以共享，仍保留每个不同的约束命题。

## Dependency Map

1. 初态常量约束与分母正性确定合法起点。
2. 区间算术包含关系保证中间值落在生成的输出区间中。
3. 条件守卫、支付、产量取整和活性检查约束确定所走的离散分支。
4. 适配器正确性将这些算术步骤关联到动作、同时生产、状态更新、池再生、衰减和维护。
5. 每轮 $h_{i,t}$ 的正下界推出全员轮末存活，产生 $NT$ 个存活人时。

## Proof

### Step 1. 合法常量与向外取整

常量生成单点区间 $[q,q]$。对非单点算术区间，下端点向下取整、上端点向上取整，因此新区间包含原区间。Lean 通过有理数交叉乘法逐项检查这个包含关系。它不采用“浮点结果大致相近”作为证明规则。

### Step 2. 算术包含

若 $x\in[l_x,u_x]$、$y\in[l_y,u_y]$，则加法结果属于 $[l_x+l_y,u_x+u_y]$，减法结果属于 $[l_x-u_y,u_x-l_y]$。乘积的极值在矩形端点的四种乘积中取得；所以包含全部四个乘积的输出区间包含 $xy$。

若除数区间严格位于零的一侧，倒数在该区间连续且单调，商的极值也由四个端点商给出。最小值和最大值分别是各端点对应的最小值和最大值；裁剪由这两个操作组合。因此这些局部包含关系可以逐个传播。

### Step 3. 确定分支

例如，$u_x<l_y$ 保证 $x<y$；$l_x\ge u_y$ 保证相反结果。无法判断时拒绝证书。若 $\lfloor l_x\rfloor=\lfloor u_x\rfloor=m$，则区间内任意 $x$ 的取整结果都是 $m$。支付和活性守卫同样通过严格或非严格区间界限检查。

池再生的全部需求 $D$ 非负且 $D\le R$ 时，每项需求得到全额供给。$D=0$ 时每项非负需求均为零，因此直接全额供给与原规则的零分配具有相同的状态结果。这允许避免无意义的零除法，同时保留转移含义。

### Step 4. 轮次归纳与生存

在适配器假设下，每轮的全部操作都由上述局部关系覆盖。初态落在常量区间内；若 $S_{t-1}\in\mathcal I_{t-1}$，逐操作包含与守卫确定性给出 $S_t\in\mathcal I_t$。归纳得到所有轮次的包含关系。

Lean 检查每个活性区间的下端点严格大于零，因此 $h_{i,t}>0$。固定人口 $N$ 下，所有 $T$ 轮均有 $N$ 人存活，累计存活人时为 $NT$。这达到固定人口、固定轮数的这个计数上界；它不是任意其他目标的最优性证明。

## Corrections or Missing Assumptions

仍缺少 JSON 到约束图的形式化编译正确性，以及 Python 浮点解释器与数学模型之间的形式化对应证明。目前逐轮比较库存、液态能源、变量、材料池、环境储备、整数生产结果、活性分支及设备权限/费用状态。数值交叉比较允许小范围浮点误差；实际产物整数和活性分支必须一致。

未知规则下的可发现性、任意允许噪声下的因果生存策略、无限时间生存和所有社会行为尚未证明。检查器拒绝的轨迹应标为未认证，不能据此断言世界无解。
