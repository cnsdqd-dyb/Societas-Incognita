# 运行框架与已确认设定的对齐

本轮落实第一批能力接口并核对状态、账本和恢复机制；没有调用付费模型，旧实验仍保持停止。离线脚本轨迹用于程序验收，不是社会行为证据。

| 已确认要求 | 当前实现 |
|---|---|
| 无外部共同目标 | 保留中性的成员操作提示，没有新增任务奖励、组织角色或合作指令 |
| 数学规则与人工能力并存 | 原有六类组合机制保持；可用 `with_capabilities` 给候选世界附加四种设备规则 |
| 获得材料才知道特性 | 正数量实际持有触发私有披露；初始库存、生产、赠送、交易、抢夺共用持有记录；零产出和挂牌不触发 |
| 知识与所有权不同 | 转让后保留学到的类型特性；使用能力按当前权限重新计算。聊天陈述不自动变成引擎验证事实 |
| 世界公开也不提前公布材料特性 | 公共材料目录只含 ID 与名称；全局规则移除材料特性和设备配方。生产配方仍由独立配置控制 |
| 材料具有燃料以外的用途 | 通信增量、持久笔记容量、限定字段测量、制造配方许可四类能力 |
| 能力有成本与权限 | 制造消耗真实材料；启用按服务人数付费，下一轮开始，限期生效；转让取消服务；停机所有者的服务暂停 |
| 任意时刻可衔接 | 轮末 checkpoint 与轮内 journal 保存知识、设备、笔记与每人成员通信预算；按引擎哈希校验恢复 |
| 通信按字符/token，最后一条完整 | 每人预算固定到本轮 journal；保留完整跨限输出，可以提前停止；设备增量不绕过基础预算为零的关闭设置 |
| 可以追查资源集中和服务关系 | 研究者指标纳入设备嵌入能量、所有权、操作计数和直接披露的材料类型数量；没有把它们直接称为组织或理解 |

实现文件：`material_knowledge.py`、`capability_devices.py`、`mini_world.py`、`interaction_controls.py`、`sim.py`。独立回放审计 `audit_actions.py` 比较材料库存、私有知识、笔记、设备、托管和账本；设备内部配方来源仅供研究者查看。

## 当前默认能力示例

通过 `prepare_capability_world.py` 生成四份可审查配置，位置 `configs/capability_fixtures_20261010`。相同基础世界分别设置有/无压力、公开/隐藏世界规则；4 个成员、50 轮、隐藏生产配方、通信基础预算每轮每成员 1000 字符，API 预算为 0。它们是验收夹具，尚未通过正式研究世界接纳，不会自动启动实验。

| 设备 | 材料组合 | 服务增量 |
|---|---|---|
| 通信 | C + D | 每位授权成员每轮增加 500 字符或统一 tokenizer 的 token |
| 记录 | B + 2C | 增加 2048 字符持久笔记容量，基础容量为 256 |
| 测量 | 2C + D | 指定状态变量读数，误差绝对值不超过 0.1 |
| 制造 | C + 2D | 获得标记配方的加工许可；示例中用于 S 生产 |

每次制造另付 1 单位 stock 和世界试验成本；嵌入能量比例 0.75，拆卸回收比例 0.5。启用付费每接收成员 0.5 单位 stock，持续 3 个物理轮次，最多 4 位使用者。数量、上限、输入和费用来自世界定义，成员未取得对应物品前不会直接收到这张研究者表。组装是一个物理动作，不执行宿主 Python/XML。

## 验证与边界

新增测试覆盖信息隔离、初始披露、双向交易、零产出、先持有后立即衰减、能量守恒、设备时序、续订、权限、转让、停机、笔记容量、测量误差、制造许可、失败回滚以及严格工具 schema。50 轮脚本运行验证中断恢复与完整运行状态相同，审计能够拒绝被篡改的设备所有者。

本轮共 156 项不同检查通过，包括 15 项新增检查。统计见 `reports/capability_validation_20261010.json`，回归细节见 `reports/capability_regression_20261010_final.log`。旧 open-world 的 50 轮组合测试先前在非持久终端下被中断，本轮未重跑，不计为通过；当前 mini-world 的 50 轮设备、中断恢复、审计和篡改检查已经单独通过。最初未完成的旧交易/游戏/救援组合检查在持久终端重跑后通过。

后续更新：设备完整度、维修、腐蚀和限时干扰已由材料功能层实现，另有作品扩容、容器保护、付费救援等 24 类作用，详见 [ARTIFICIAL_MATERIAL_SERVICES.md](ARTIFICIAL_MATERIAL_SERVICES.md)。该层还保存私有组合发现、确认/取消和实际作用状态。仍未实现材料批次纯度/寿命、设备空间位置、自动化设备及其余候选设备。材料说明的“可作为组件”不等于公布完整配方；消息理解与知识传播因果效果仍需要后续测量。

新增材料服务的 101 项离线回归验收见 `reports/functional_services_20261010/acceptance.json`，与上面的早期验收存在重叠，不相加。原有有界数学状态组合已有 Lean 支持；新增服务和破坏作用尚未完整形式化。仅实体动作审计不能重建共享通信额度消耗，含会话功能的完整复核须保留通信轨迹并使用完整引擎回放。

第一步时 Lean 仅检查受限 wait/gather/liquidate 策略。随后新增了 [确定性组合及设备路径的区间约束证书](COMPOSED_LEAN_SUPPORT.md)，八条设备路径和一个六机制世界通过核检查。它不证明未知规则下成员能发现策略，适配器和浮点语义对应仍有证明边界；随机世界筛选、能力净收益和真实模型实验仍需独立完成。
