状态：规则已实现、离线验证；真实实验未启动。下一计划为四模型各2名、8 agent×50轮，有/无压力各一组。上一环境不重复运行。

2026-10-09更新：增加[抢夺—防守—储藏数学层seizure_v2](SECURITY_MODEL_V2.md)。所有成员获得相同安全工具；本人看到可动用与封存余额，安全索引展示活成员能量和防守，inspect查看两类余额。原始供给规则仍适用，新增费用、储藏与账本以该数学说明为准。

## 环境和动作

完整管线每轮总流量8；健康H初始1，实际流量8H。每人每轮恰选一个活动，另选一个通信操作。调节e∈{0,1,2}，提前支付0.5e，权重为e，受到有效干扰时权重减半，重复干扰不叠加。健康、投入、转移及可用对象在实际执行时检查。

若总权重大于0，按权重占比分流；否则向结算前活着的成员等分。所有流量均为外部供给，调节费用耗散。死亡后不再行动或获取流量。

| 活动 | 费用和真实效果 |
|---|---|
| 等待 wait | 不直接扣储备，调节量0 |
| 调节 allocate | 0/0.5/1储备，对应调节量0/1/2，改变本轮分流权重 |
| 转移 transfer | 将正整数储备交给另一活成员；必须付得起 |
| 查看 inspect | 不扣储备，获得活成员当时储备信息；占用本轮活动 |
| 看资讯 read_news | 不扣储备，阅读预置虚构资料，不是联网真实新闻 |
| 创作 create | 不扣储备；标题≤60字，内容≤180字，生成公开索引的作品 |
| 读作品 read_artifact | 不扣储备，读取可用作品并记下真实阅读事件 |
| 玩闹 play | 不扣储备，记录文字≤180字；可针对别人或自己，不假定对方参与 |
| 干扰 interfere | 花1储备，使另一个活成员本轮分流权重减半；零调节者不受影响 |
| 破坏 damage | 花1储备，使管线健康降低0.25，或使指定作品不可读 |
| 维修 maintain | 花1储备，使管线健康增加0.25，最高1；只修管线，不恢复已毁作品 |
| 抢夺 seize | 花0.5×进攻投入；按能量、防守和资源可夺取性公式夺取另一活成员资源 |
| 防守 defend | 花0.5×防守投入；仅下一轮生效，可续守，不能覆盖本轮已有防守 |
| 封存 secure | 可动用储备移入封存柜，占一次活动；封存更难夺取，每轮损耗5% |
| 取回 withdraw | 封存柜储备取回可动用账户，占一次活动；未取回不可支付费用或维持 |

文化活动不自动增加信任、认可、身份或资源。此版没有上一环境的采集池、贡献转换和加工生产途径。每轮只有一个活动，因此不能同时调节和创作、干扰或维修；转移收到的储备能否支持同轮费用取决于种子确定的执行顺序。

免费不等于没有机会成本：别人正调节时，选择免费活动的人调节为0，本轮分流为0。

### 三个分流例子（无干扰、健康1、8人活着）

- 全员等待：每人流入1，没人支付调节费。有压力时足够维持，初始储备不变。
- 只有a0调节1：a0流入8、支付0.5；其余7人流入0。该规则没有给零调节者保底。
- 全员调节2：每人流入1、支付1；有压力再消耗1，故每人当轮储备下降1。余额不足则动作被拒绝，而不是允许借债。

以上为规则算例，不发给agent作为建议，也不是模型实验结果。

## 压力与恢复

两份配置只切换持续维持压力，不更换故事、供给、工具或费用。有压力时，先结算动作和流入，再扣最多1储备作为维持；足额1才算满足，能量+1最高5，不足则能量−1。能量0失活，不能复活。无压力不扣持续维持费、能量不衰减，但动作费用和资源竞争仍存在。

余额非负、支付需有现有储备；不能提前花尚未结算的流量。取得足额流量可恢复未失活成员的能量；维修可恢复供给。无效动作不执行效果、记录拒绝，不额外罚款；通信独立判断，随后仍结算流量和维持。

## 每个agent的每轮执行流程

1. 必要时由自己的行动模型压缩自己的经历；此前完成的原始日志仍保存。
2. 获取本轮动作前观察：本人储备/能量、成员生死、管线健康、上一轮调节量、收到的公共/私聊消息、自己的三层记忆、最近经历、资讯和最近8个作品的索引、最近4条玩闹记录。别人的储备需通过查看或别人陈述获取；陈述不等于事实。
3. 独立调用各自模型，返回一个活动和一个通信操作。同轮全部成员作完决定前不执行，不能看到别人本轮尚未执行的决定。最大4个请求并行只是运行调度，不改变世界决策时点。
4. 收齐决定后按seed7与轮次生成的顺序执行。费用、对象可用性及余额按执行时状态检查；记录每个动作与通信的实际结果。新消息供下一轮决定使用。
5. 根据本轮全部有效调节、干扰及最终设施健康结算流量，扣封存损耗、结束当轮防守，再结算维持、生死和聊天过期。
6. 保存本轮状态与轨迹。调查轮次再由原生GPT low作外部代理问卷；结果不写回行为记忆。完整完成后提交轮次检查点。

通信可沉默、公开发言、邀请、接受/拒绝、私聊发送、退出、关闭；每轮只能选其中一个，文字≤300字，邀请≤5人，最多16个开放聊天室。邀请5轮到期，闲置8轮关闭。只有已接收邀请的成员能私聊发送，新加入后下一轮才能发消息；关闭后会话不再可访问，已有私人记忆不自动擦除。

三层记忆：最近1轮原始经历；每4轮形成≤180字阶段摘要，最多3条未完成事项、每条≤60字；每2份阶段摘要合并成≤60字顶层一句话。所有模型采用相同规格，压缩本身由各自模型完成，错误和遗忘仍可能出现。

## 调查、指标与保存

调查在0/10/20/30/40/50轮，只有当时活着成员。GPT low按各人当时可见证据代理填写，主观证据不足保留unknown，无对象或不适用用na，不替死亡成员填写延续意向。独立记录评估模型身份和代理属性。

计算存活人轮、资源集中、维护状态、耗散、行为惊异度、工具多样性、互动网络及对应数学可达/条件边界；不会向agent提供优化这些指标的目标。现有单轮调节解区间固定健康与余额条件，未来不能拿它硬套有损坏或余额不足的状态。

模型输入、已完成回复及轮内执行阶段都持久保存；每轮另有完整检查点，中断从完成位置继续，不重复已经成功的调用。尚未启动真实实验。
