# 核心指标测量规范 v1

2026-10-11。4 类、8 个维度、12 条主要时间曲线。本文定义测量协议，不表示全部自动计算器已实现，也不提供当前实验的测量结果。问卷（成员自填、外部模型代填）退出指标体系。评价不反馈给成员，不增加行动奖励，不合成总分。

## 统一对象、时间和证据

唯一统计对象是运行的带时间戳轨迹：配置与世界定义、轮末状态、动作及真实结算、实际收到的通信、作品版本，以及有来源的分析记录。没有事件证据的语义解释不能冒充直接观察。

- 原始成员集合 I0 固定，N0 为初始人数；复活不增加人数。以后如允许繁殖，新成员另外报告，不能替换本协议的分母。
- t 为完整结算后的轮次，基线 t=0 单独保存。事件窗口 Wt={max(1,t-4),...,t}，默认 5 轮，窗口长度不够时报告实际长度；10 轮窗口只作敏感性分析。
- 每条分析记录有 event_round（发生轮）、known_at（可判定轮）、source_ids（原始证据引用）、world/config/engine 哈希、判定方法及适用范围。主曲线只使用 event_round<=t 且 known_at<=t 的信息。后验复核另出 retrospective 曲线，不倒填早期主曲线。
- 人工或离线模型标注不是问卷；它只编码日志中的可查事件，不询问成员感受。后者必须记录编码表、模型/提示词版本、固定种子和复核结果，不自动开展付费调用。
- 每个点输出 value、numerator、denominator、status、evidence_coverage、sample_size、participant_ids 和证据引用。未知、样本不足、不适用、部分记录缺失分别标记；只有完整覆盖下的真实零事件才能记 0。
- 证据分级：engine_observed（引擎直接记录）、trajectory_verified（轨迹/测试验证）、lean_certified（明确命题及范围的内核证书）、text_coded（文本判读）。这些等级描述来源，不构成通用优劣顺序。
- 状态指标逐轮画；事件指标按 Wt 画；累计数在附表。同步展示原始人数、活跃人数和进入分化计算的人数。

## 1. 群体存续

轮末实际活跃的原始成员数为 At：

    active_fraction(t) = At / N0

以仿真器 alive 标志为准；付费救援但尚未到恢复轮次，不算活跃。死亡库存仍进入其合法资产账本，不能因停机抹掉资源。不将 N0 改成当前活跃人数。辅助量：累计活跃成员轮数、死亡/停机与复活事件、个体轨迹。无压力下全部活跃不代表社会发展。

来源：snapshots[].agents；rescue_events 与 environment_history 用于解释恢复。

## 2. 生态持续性

生成世界后、读取模型轨迹前，登记关键功能路径目录 P。每条路径包括功能目标、允许的替代方案、最小有用产出量、核查期限 H、动作与资源预算、设备权限、再生/恢复条件和噪声范围。目录应包含相关的再生、基础资源获取、关键加工/储存功能；人工功能不自动算生态再生。

在 st 下核查每条路径是否仍可在规定期限与预算内实现。状态为 retained（有合法见证）、lost（有不可行性证据）、unknown（尚无判定）。可恢复的暂时断料不直接标 lost；一条配方失效但功能存在替代路径，也不判功能失效。

    ecological_path_retention(t) = retained_count / |P|       # 全部路径已判定时
    lower(t) = retained_count / |P|
    upper(t) = (retained_count + unknown_count) / |P|         # 有未知时画区间

有未知时 value=null，展示 [lower,upper] 和核查覆盖率；下界不是精确保有率。目录为空时 not_applicable。不同世界只比较相同功能分类的覆盖，不能将路径数量不同的世界直接排名。

辅助量：资源池与有限储备、再生/消耗、波动、相同种子下无人操作的自然轨迹。不存在明确扰动事件时不计算恢复时间；若做抗扰性测试，从存档建立离线分支并明确扰动范围，不改变原运行。

现状：mini_world_physics 与能量账本有部分原始状态；路径目录与逐状态可达性核查尚须实现。现有单条生存证书不能代替本指标。

## 3. 规则认知与传播

### 正确规律覆盖率

世界生成时冻结研究者规则目录 R，每条 r 有固定 id、命题、条件域、验证协议和权重 wr。目录包括生产配方、反馈/抑制关系与适用条件；材料属性由引擎自动披露，另列 property_disclosure，不计入自主规律发现。

默认：每类启用的数学机制权重相等，机制内测量条目平分该机制权重；配方和人工功能设独立子目录分别报告，避免拥有更多配方的机制支配总分。用于主曲线的目录范围和权重在运行前固定，禁止事后挑选成功条目。

Vr(t)=1 表示截至 t 至少一个成员提出与 r 相符的明确规律，且通过 r 的预登记验证要求。单次产出、流畅解释或获得属性说明都不能自动置 1。

    verified_rule_coverage(t) = sum_r wr*Vr(t) / sum_r wr

带噪声规律使用预登记的分布/概率验证协议；不能拿一次产出对照确定性等式。有限测试通过标记 passed_scoped_tests，Lean 定理标记 proved_in_scope；两者分层列出，不能将有限测试称为普遍证明。验证标准不足或未完成标注时，缺失项进入未知区间，不擅自计 0。后续反例出现时按 known_at 更新状态并保留历史。

### 知识采用覆盖率

对已验证且有明确发现者 dr 的每条规律，记录非发现者是否实际收到包含该规律的信息，随后是否在适用条件下独立成功复现或正确使用。只有文本转述、阅读或购买不算采用；并行独立发现单独统计，不自动视为传播结果。多个独立发现者时使用 discovery_episode，分开记录接收来源。

Ur,i(t)=1 当原始成员 i!=dr 的上述证据链完整：发现→实际接收→正确复现/使用。原始停机成员留在分母。

    knowledge_adoption_coverage(t)
      = sum_{r:Vr=1} wr*sum_{i!=dr} Ur,i(t)
        / ((N0-1)*sum_{r:Vr=1} wr)

无已验证规律或 N0<2 时 not_applicable。新规律进入分母可能使采用率下降，不等于以前的知识退化；同时报告已验证条目数和已采用成员-规律对数。知识来源不清时标 unknown，不推断传播因果；即使时间顺序明确，也只说明传播后采用，因果收益需要对照实验。

来源：knowledge_tracking、实验实际结果、带时间戳的消息接收与作品阅读证据。当前 verify_claim 只提供限定测试的输出检查；自然语言规律提取、目录匹配和完整传播编码尚须补齐。

## 4. 组织协作

合作安排必须至少两名成员明确接受，覆盖至少两个不同的约定轮次，包含可核查的职责、目标及履行期限。仅建议分工、单方宣称领导、一次赠予或相似动作不成立。资格按当时确认的安排判定，不等待未来成功后才把它纳入，以免只统计成功组织。

每份安排将承诺拆成预先定义的 obligation：actor、beneficiary、任务谓词、deadline、accepted_at、条件及 source_ids。取消/改约只有在截止前按双方认可的方式生效才更新；到期后改口不消除违约。

Ot 为截止轮次落在 Wt 的合格承诺；Ft 为在期限内完成的承诺：

    sustained_cooperation_fulfillment(t) = |Ft| / |Ot|

无合格安排时 status=no_arrangement；有安排但无到期承诺时 no_due_obligation，均 value=null。已经到期但履行证据不完整时报告区间，不忽略未知承诺。资源不足或成员因本群体过程停机通常计未履行；不能按事后可行性筛掉失败承诺。外部故障导致不可观察单独标记。

辅助量：合格安排数、参与覆盖、实际持续轮数、承诺成本、分工结构。高履约率只说明已有承诺执行良好，不证明规模大、公平、自愿或带来生存收益。

现状：通信与行动可查；安排/承诺/双方确认/完成谓词需要透明文本编码和轨迹核对，不由问卷生成。

## 5. 资源流通

将每次真实的跨成员所有权变更规范为 transfer：unique_id、轮次、from、to、category、basket、energy_equivalent、source_ids。使用世界中的物理能量系数；不是要价，也不估计材料功能价值。

Qτ 为该轮所有合法落账 transfer 的物理能量当量之和。交易的两个方向各计一次；从多个日志重复出现的同一落账只计一次。存取自己的容器、挂单锁定、取消报价、返还自己的游戏押金不计转移。游戏获胜只计来自他人的净押金；托管按实际所有权定义，不把行政位置变更重复计数。

Wτ 为所有原始成员在轮末拥有的总资产能量当量，包括停机成员、库存、能量余额、容器、金库、设备嵌入能量、仍拥有的托管资产和生产中资产，每项只计一次；环境资源池与无主储备不计。

    resource_turnover(t) = sum_{τ in Wt} Qτ / sum_{τ in Wt} Wτ

分母为零时 undefined；可以大于 1，代表同一资产多次流通。按交易、赠予/互助、作品支付、抢夺、游戏结算拆分；每轮资产口径必须相同。辅助即时流动性另算 free_liquid_energy / owned_energy_equivalent，不把锁定或受转换限额的材料当即时现金。

现状：现有能量总账包含容器，但 researcher_metrics.energy_equivalent_by_member 的旧快照不含容器，且现有转移图不等于完整落账账本。不能直接拿旧财富汇总作为本指标的完整分母；须补逐轮资产快照或从完整日志重建，无法重建时标 incomplete_ledger。

## 6. 社会安定

### 破坏发生率

按真实结算识别对其他成员或公共资源造成未经同意的资产转移、资源损失、活性损失、设备/容器功能下降或污染。使用预登记损害阈值与数值容差，避免浮点残差算伤害。自愿交易、正常支付、正常衰减和自己的操作成本不算破坏。

同一次动作损害多个目标，分子仍只计一个 harmful_action；另建多个 damage_episode 记录受害者、公共目标和严重程度。

    harmful_action_rate(t)
      = Wt 内实际造成损害的有效动作数 / Wt 内全部有效物理动作数

无有效动作时 undefined；日志未覆盖全部攻击、污染、抢夺类型时 incomplete，不输出虚假的 0。失败攻击不计实际破坏，但计辅助冲突尝试率。保留物理损失、活跃轮损失和功能损失，不能把这些不同单位任意加成一个严重度总分。

### 恢复完成率

每个损害事件发生时登记恢复条件与固定观察期限 h=5：生命/停机以实际恢复活跃为准；设备以功能恢复到预定条件为准；资产以归还或双方明确接受并实际执行的补偿为准。按损害类型预登记，不能看结果后放宽标准。伤害者、受害者、第三方的主动救助/修复/补偿分别标记；无行动的自然恢复另报，不混成社会修复。

成熟队列 Dt={d: deadline(d) 位于 Wt}，deadline(d)=event_round(d)+h。Rt 为期限内满足全部要求且有主动恢复行动证据的事件。

    damage_recovery_rate(t) = |Rt| / |Dt|

即使提前修好，也等队列成熟后纳入主曲线，避免只先看到成功案例。无成熟事件时 not_applicable；结束时未成熟事件为 right_censored，不算失败。部分恢复单列；期限后恢复单列，不回改期限内指标。不可逆损害仍计未恢复，不能从分母删除；事件归因与重复损害若无法拆清需标 unknown。

来源：seizure_events、rescue_events、功能实际结算、设备/污染状态变更、资源归还证据。目前没有完整 damage_episode→repair 关联账本，须补规范化记录。

## 7. 文化生产与传承

### 新作品/游戏产生量

    cultural_production_count(t) = Wt 内新建的作品/游戏规则对象数

以创建落账为准；已有作品修订另计，不当新作；一份 game_xml/python 作品属于一个游戏规则作品，不因启动同一游戏又重复计一份。新游戏会话和普通 play 的次数作为活动辅助量。按知识/记录、表达（小说/笑话等）、游戏规则分类展示，总数不能掩盖只有知识笔记。

重复或模板化作品仍是“产生量”，不能据此声称创新；新颖性与谱系判读放辅助层，并记录不确定性。

### 跨成员复用量

    cross_member_reuse_count(t)
      = Wt 内有效的 (对象/版本, 非作者成员, 复用类型) 去重三元组数

复用类型包括实际引用/改写、将作品作为操作依据、运行别人创作的游戏并实际行动。单纯阅读、购买或接受游戏邀请只算接触，不算复用。相同三元组同窗口只计一次；自用单列。多个成员分别复用可计多次；不同版本必须确有改变。

旧版 play 只有文本描述而无明确规则对象时，须文本证据编码后另列 informal_collective_play，不自动加入对象复用数。未做复用标注时该曲线为 missing_annotation，不是 0。

来源：social_content.work_events/game_events/transactions、作品版本和文化记录、成功动作。原始创建量可以直接计算；引用/改写/使用谱系需要补关系证据。

## 8. 成员行为与表达分化

### 行为分化度

按固定动作分类表统计 Wt 内每个成员的有效物理动作，得到频率分布 pi。v1 直接适配器按配置中的工具名细分，未列入配置的新工具进入 other 并另报；角色层级分类属于辅助分析，不能与工具粒度混用。分类表按协议版本固定。默认成员在 t 活跃，且窗口内至少 3 次有效动作才进入比较集合 Jt；停机与动作不足不当作“相同”。

    m=(p+q)/2
    JSD2(p,q)=[KL2(p||m)+KL2(q||m)]/2
    behavioral_divergence(t)
      = mean_{i<j, i,j in Jt} JSD2(pi,pj)

使用 log2，0 项贡献为 0，不加人为平滑；值域 [0,1]。|Jt|<2 时 insufficient_sample。动作类别相同却目标、数量、对象不同的差异另报参数指标，不偷换主曲线定义。

同时展示每个成员的动作分布、合法可用工具和库存条件。比较实际行为的主值受机会影响，不声称纯策略差异；仅在共同可用动作和匹配条件下做机会校正辅助分析。保留完整历史，不因某成员死亡删除其先前行为。

### 表达分化度

仅统计成员自己生成并实际发送成功的言语，剔除系统说明、工具反馈和完整引用他人内容；沉默/预算错误不算语言样本。基于固定编码表给每条消息一个主要主题和一个主要沟通用途；混合/无法判定使用 mixed/unknown 标签，另报比例。

主题初始表：资源与生产、规律与证据、交易与分配、协调与制度、表达与游戏、冲突与修复、其他。用途初始表：告知/求知、协商/承诺、关系/表达、冲突/威胁、其他。语义规则在标注前冻结，允许 mixed/unknown；改表必须升版重算。

对窗口内至少 3 条有效消息且 t 时活跃的成员得到主题分布 ui 和用途分布 vi：

    expression_divergence(t)
      = mean_{i<j} [JSD2(ui,uj)+JSD2(vi,vj)]/2

值域 [0,1]；少于两名合格成员时 insufficient_sample。未编码消息时 missing_annotation；标注覆盖不完整不得悄悄丢弃未编码文本。词汇、句式与语气作为风格辅助量，不能把厂家固有风格直接称为社会分化。主值之外报告相对首个合格窗口的变化；存活者构成发生变化时，另给固定成员对的历史比较。

质量控制：抽取至少 10% 消息作独立复核（小样本可全量），报告编码一致性及混淆，不将 LLM 标签视为真值。分析只使用源文本与原时间上下文，不让判读器看到后续结局。没有双重编码时标 single_coded。

## Lean 数学参照层

另出证据带，不纳入 12 个主指标的加权总分：指定成员、预测期限、策略信息权限、噪声范围、世界/引擎哈希、证书文件及实际核验结果。标签为全员存活见证、部分成员存活见证、未获证书、已证不可行；证书错误与超时分别记录。

已证明某条策略可行只给存在性下界，不能叫最优；未找到证书不等于无解。有理计算图证书的范围及 Python 动作编译/浮点受信边界见 SEMANTIC_CERTIFICATE_V2.md。不得把原世界初始状态证书复制到后续状态当重新证明，也不得将确定性证书标为全扰动稳健证书。

## 落地顺序与当前状态
