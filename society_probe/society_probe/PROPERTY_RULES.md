# 可推断属性规则层

这是现有世界引擎的可选扩展。旧配置、已冻结实验与旧轨迹不迁移。

## 构造与执行

```python
from world_rule_library import generate, with_capabilities, with_property_rules

candidate = with_property_rules(with_capabilities(generate(19, [
    'renewable_ecology', 'cross_feeding', 'explicit_delay', 'shared_queue',
    'fatigue_repair', 'finite_buffer', 'power_limited_storage',
    'calibrated_measurement',
])))
```

先生成原有数学机制和生产图，再加设备层，最后加属性规则层。
第一版复用原有数量、产率、状态条件、反馈方程和能量预算；将反应入口
转换成有限属性上的逻辑规则，不重新构建整个世界系统。

物质具有光学响应格、标准场偏转方向和孔隙响应。设备模式具有可观测的
通道读数与校准样片记录。它们是人工世界中的属性，不主张自然物理真实性。
世界种子决定属性和设备通道，描述通过固定模板由实际事实生成。

隐藏规则采用 `and`、`or`、`not`、`eq`。例如：

```json
{"and": [
  {"eq": ["device.channel", 240]},
  {"eq": ["slot0.band", 7]},
  {"or": [
    {"eq": ["slot0.direction", 1]},
    {"and": [
      {"eq": ["slot0.direction", 0]},
      {"eq": ["slot0.porous", true]}
    ]}
  ]}
]}
```

这是语法示意，不是某个已发布世界的配方。完整反应还包括其它投料位置
的条件、化学计量、输出和原有状态条件。可写作：

`材料属性条件 ∧ 设备属性条件 ∧ 当前数学状态条件 ⇒ 转化及状态变化`。

编译器枚举当前世界的材料绑定、加工台和模式，生成现有引擎执行的反应。
因此相同条件下，同属性材料可以替代；析取的不同分支也能实际触发反应。
不会根据智能体文字猜测改变物理事实。

## 成员观察

- 初始资源池中有样本的材料提供描述性观测，作为可检验假设的线索。
- 首次持有后私下获得描述性属性记录；材料组合功能仍按原有私有持有条件解锁。
- 加工台提供模式对应的校准记录，不给出配方、投料比例、产物或产率公式。
- 原来可观察的动态状态改为逐轮探头读数描述。不可观察变量仍隐藏。
- 样本描述和私有材料描述由同一属性对象生成，不能互相矛盾。
- 角色发言是其主张，不作为世界事实或研究者验证结果。

这是第一版的理想化观测：探头属性描述为确定性读取；尚未模拟获取初始样本
读数的测量动作与成本。既有有界噪声、设备测量误差仍按其原有机制执行。
描述性呈现并不意味着把所有数量都模糊化，库存和实际投入产出仍保留精确数值。

## 限制性原料

新层使用 `limiting_reagent_v1`。对已匹配的材料集合与加工模式：

`反应量 = min(实际投料_i / 化学计量_i)`。

只有实际消耗的材料与实际支付的操作能量用于产物能量预算，多余材料返还。
反馈明确记录 `consumed_inputs` 和 `returned_inputs`，成员能通过实验估计比例。
模式或材料集合不匹配、状态条件不满足时，材料按原有逻辑返还。
队列中衰变、设备最低加工量、制造能力要求仍有效。

旧 `proportional_v1` 的精确比例行为不变；新行为仅对显式使用本扩展的世界生效。

## 一致性与证明边界

检查器穷举声明的有限材料、设备和模式，拒绝不可满足的规则、未知属性、
有多个反应可匹配同一材料集合与模式的情况，以及规则、执行图、设备描述不一致。
即使两个重叠规则可能具有互斥的连续状态条件，本版也保守拒绝，而不猜测互斥性。
新增材料或修改属性后，需要显式 `property_rules.refresh(definition)` 并重新验证。

有限一致性检查不证明科学可发现性、探索余量、全员存活或最优性。原有数学
状态更新和物理能量账本继续生效。限制性原料结算尚未扩展到组合模型Lean编译器；
编译器明确拒绝新语义，不能复用旧证书来宣称新世界被证明。Python浮点运行时
继续属于受信边界。
