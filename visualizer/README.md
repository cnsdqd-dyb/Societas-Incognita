# Society 像素观察站

在仓库根目录运行（Python 标准库，无需安装依赖）：

```powershell
python visualizer/server.py
```

打开 http://127.0.0.1:8776 。也可以双击 `start.cmd`。端口被占用时通过 `--port` 修改。

项目介绍位于仓库根目录 [英文 README](../README.md)，并链接到 [中文 README](../README.zh-CN.md)。不另设项目介绍网页。

新增工具：`/lab` 是二十种机制的离线参数演示，`/works` 是作品和游戏档案，`/` 与 `/replay` 是智能体回放。演示直接使用研究引擎的物理结算，不调用模型，不修改实验。可导出完整规则与逐回合 JSON。

README 的动态 SVG 展示材料依赖、实际生产、成员间转移与数量曲线；SVG 不包含脚本，动画使用 SMIL。GIF 对照三组机制组合。配图的公式供研究者查看；隐藏规则设置不会直接向成员披露这些公式。所有配图轨迹是固定操作探针，不是智能体研究结果。

作品用文本节点渲染；Python/XML 游戏经现有有界解释器独立试玩。新格式 `communication_events` 进入气泡与通信统计，物理行为分布仍只统计原始行为事件。材料库存与守恒账本区分物理能量和活性状态。

- 从 `society_probe/society_probe/runs` 自动发现已有 checkpoint；支持环境、模型、配置筛选。
- 不同机制采用不同场景内容与配色：森林采集、暖陶共享、紫晶蓄能、沙漠竞争、蓝湾协作、钢蓝加工、青蓝电路。
- 每个实验的身份（运行目录、环境、机制、实验种子）通过固定哈希映射为 32 位展示种子，显示为「布局 #编号」。建筑位置、场景装饰和角色出生点由该种子决定。同一实验刷新、重新打开、跳回开头或新增回合时保持一致；不同实验生成不同布局。
- 随机出生点位于可通行网格，并保持角色间距；装饰采用对应碰撞盒，生成时检查可通行区域连通性。展示种子独立于实验模型采样种子，不改变真实实验数据。
- 回合回放、拖动时间轴、上一回合 / 下一回合、0.5–16 倍速，默认 16×；空格暂停。
- 智能体走到对应设施执行行为，动作和通信展示 emoji 气泡；格网寻路避开建筑，圆形碰撞避免角色重叠。
- 点击角色或时间线事件，右侧查看原始动作、执行结果、对话、已记录思考 / 当时的层级记忆，以及原始响应和决策上下文。
- 完整回合以 checkpoint 的 settled events 为准，未完成配置明确标注为部分记录；暂停时每 30 秒刷新，也可手动刷新。
- 成员间转交和夺取按实际结算数量显示定向资源包动画、数量和双方增减；加工展示设备编号、操作进度、等待任务与已完成产出。
- 对话以蓝色文本气泡分组显示，停留时间可选 0.5 / 2 / 3 / 5 / 8 秒，默认 0.5 秒，倍速不缩短阅读时间；思考只在右侧紫色区域展示。暂停行动阶段可仔细观察资源动画，再继续进入对话。
- 左侧包含能量 / 库存与回合变化、能量曲线、行为分布、公共 / 私聊发言排行及三类有向互动图。统计范围可选截至当前回合、仅当前回合或全部已有记录，顶部导航可以跳到对应图表。
- 点击关系边或关系列表显示原始事件证据；点击证据跳到相应回合并展开右侧详情。
- 交流图：公共发言指向公共频道，私聊按记录的实际接收者展开，邀请为单独虚线。不把公共广播当作两人亲密关系。
- 资源图：成功转交从发出者指向接收者，成功夺取从被取走者指向获得者，权重为实际资源总量；不计失败请求、存取自己的储备或共同生产为成员间转移。
- 文化图：作者 → 读者表示作品阅读传播，娱乐发起者 → 目标不代表目标参与，作者 → 作品库表示创作；作品破坏单独以虚线标注。不推断未记录的文化影响或模仿。
- 日志未记录思考时会明确显示缺失；不会生成或推断思考文本。合成实验保留 MOCK 标记。

角色位置、走动与碰撞仅为展示动画，不是实验物理轨迹。程序只读实验文件，不调用模型，不修改运行任务。服务只监听本机。
