# README media

- `compositional-world-laws.svg`: script-free, animated SVG using SMIL. Quantities, highlighted production dependencies, and handoff events come from `compositional-world-laws-data.json`.
- `material-functions.svg`: a conceptual diagram of private combination discovery, confirmation/cancellation, and implemented capability, survival, and destructive effects. It uses the same palette and reads the implemented service count; it is not an experimental trajectory or Lean proof.
- `material-functions.zh-CN.svg`: the matching Chinese diagram, used by `README.zh-CN.md`; generated by the same builder with the same layout and palette.
- `mechanism-combinations.gif`: three engine-computed compositions, rendered as 62 looping frames. The editable static SVG and PNG share the same renderer. Full definitions and trajectories are in `mechanism-demo-data.json`.
- `mechanisms/01.svg`–`20.svg`: mathematical inspiration cards arranged as four columns and five rows in both READMEs. Each card is paired with a source link. These show source formulas or explicit world proxies, not a claim that every original natural model is implemented unchanged.
- The main hero illustration is `../../visualizer/assets/material-worlds-hero.png`, generated with the built-in imagegen tool. It is an artistic overview, not experimental evidence.
- `agent-actions.png` and `material-roles.png` were generated with the built-in imagegen tool, using that hero as a visual reference. Five equally spaced scenes illustrate communication, production, creation, disruption, and rescue; five object groups illustrate energy, raw materials, intermediate products, works, and capability devices. These are conceptual interface illustrations, not recorded physical scenes.

Both trajectories use deterministic fixed operation probes, no language model, and no survival maintenance. The handoff probe uses one operation per member per round. Physical accounting is checked against the actual engine at every round. Material bars and moving pixels illustrate logged quantities and settled events; their geometry is not recorded spatial physics.

Regenerate from the repository root:

```powershell
python visualizer/build_world_laws_svg.py
python visualizer/build_material_function_svg.py
python visualizer/build_readme_media.py
python visualizer/build_mechanism_atlas.py
```

The GIF renderer additionally requires Pillow and the configured fonts. SVG generation uses the standard library and the repository engine.
The formula-card builder requires Matplotlib and reads the project's mechanism source notes. The compact GIF contains material quantities and settled production pixels; formulas and their sources are presented separately in the atlas.
