# 邮局的第四只盆

这篇故事接着《浮岛短篇》里那间漏雨的邮局写下去。孩子收到给明天的回信后，一直觉得邮局还缺一点什么。他想了三天，终于带来第四只搪瓷盆。

“雨只有三个漏点。”邮递员说。孩子把盆放在没有漏雨的地方：“这只用来接晴天。”

大家路过时都觉得好笑，但没有谁把它搬走。面包店的老板偶尔往里面放一块温热的小面包；裁缝留下两颗颜色不一样的纽扣；琴师有一天带来一截断掉的琴弦，说它至少可以当一条细细的桥。

春天将尽的时候，第四只盆里长出一株小草。没人知道种子是怎么来的。邮递员给它取了一个很长的名字：没有地址也没有退回的小东西。孩子觉得这个名字太累，最后只叫它“来信”。

屋顶终于修好了，三只接雨的盆被收进柜子。唯独第四只盆留在窗边。阳光照过来时，小草在白色的盆底投下影子，像一个还不会写字的人，用最慢的笔迹给街道写信。

后来，每个人经过邮局都会先看一眼窗户。没有新故事发生的日子，小草只是多长一点。那一点点也很够了。

这是 a3 的续篇，保留了原作的孩子、邮递员和雨天，又为那间邮局添了一只装晴天的盆。
