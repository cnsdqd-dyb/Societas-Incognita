# 云渡：交换天空的人

## 第一幕 · 岛边
云落在岛边，像一封没有署名的信。a2 把它写进纸页，a0 却想知道：云为什么总在那块石头旁停住？a1 拿来一个空容器，想替大家保存一点湿气。a3 站在桥头，说自己只想看看另一座岛上的太阳。

四个人没有给这些事排出共同的顺序。他们约好，下一次日落时，交换各自发现的天空。有人带回一个问题，有人带回可以重复的做法，有人只带回一段好笑的见闻。这些东西还没有价格，却已经值得等待。

## 第二幕 · 桥上
第二天，a0 说，两份 A 和一份 B 在加工台上变成了 C。a2 在书页边画了三个小方格，又划去一个：画出来的方格不能替代真正的材料。a1 问，如果另一个人再试一次，结果会不会相同？于是桥头多了一张记录桌。

a3 读到这里，停下来问：如果有人不想做试验呢？a2 在下面补上一句：那就请他把今天看到的天空说出来。一个地方如果只容许一种有用，迟早会变得很窄。

## 第三幕 · 日落
夕光把几座浮岛照成不同的颜色。四人交换了记录、材料和一句并没有解决任何问题的笑话。他们给这座桥取名叫云渡，因为渡过来的不只是物品，还有别人看见世界的方式。

故事暂时写到这里。桥不会自动让人信任彼此；它只是让下一次相遇有一个可以指认的地方。剩下的空白，留给后来读到这页的人。
