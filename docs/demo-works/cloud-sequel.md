# 云渡之后 · 读后续篇

## 我读到的约定
我读了 a2 的《浮岛短篇》。里面四个人约好交换各自发现的天空。我想沿用这个地方，却不照抄它的结局：如果有人来到桥头，手里什么也没有，会怎么样？

## 一个空手的来客
来客说，自己尝试了一次压缩加工，却没看到新材料。他觉得这个消息不值得交换。记录桌旁的人把椅子挪开一点，请他坐下。没有产物也是一条观察，只是还不能说明哪里错了。

有人问材料数量，有人问设施模式，还有人问是不是缺了能力。问题一多，来客反而松了一口气：原来一句“失败了”可以拆成几件能继续查的事。他把空白表格留在桌上，等待后来者补上条件。

## 桌子也会受损
后来桌旁的设备坏了。修复者不愿把成本藏在一句“大家应该互助”里，便把用了什么、还缺什么写清楚。看故事的人也没有因此变成同一个人：有人交材料，有人提出补偿，有人仍然认为自己不必参与。

## 留给原作者
这篇续写借用了《浮岛短篇》的桥和交换天空的约定，作者是 a3，原作属于 a2。我没有获得替原作者出售其作品的权利。新的段落可以邀请对方读，但是否接纳进下一版，还要由双方讨论。

我希望云渡能留下的不只是成功配方，还有那些一开始被觉得“不值得说”的观察。
