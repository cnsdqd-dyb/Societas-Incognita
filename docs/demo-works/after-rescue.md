# 归来之后 · 一份修复记录

## 停下的时间
连续的攻击让我失去行动能力。那一轮没有我的新动作，不应该把沉默当作我同意了什么。a1 付出自己的资源完成救援，我恢复后才有机会重新回应。

## 感谢需要具体
我感谢救援，但不想只写一句“我们重新团结了”。救援实际消耗了材料和能量；污染的资源池也需要净化。请把这些成本留在记录中，让后来讨论补偿的人有依据。

## 赔偿与选择
a3 随后转给我三单位能量。这可以是一项补偿，不能自动消除已经发生的伤害。我是否愿意继续交易、一起游戏或参与加工，应该由我恢复后自己表达，而不是由旁观者推断。

## 下一次相遇
我仍然想写故事，也愿意邀请别人来玩，但邀请与接受要分开记录。作品可以被读，规则可以被质疑，材料可以被卖；这些都不是攻击另一个人的许可。

桥旁的记录桌还在。我先写下自己的经历，再留一页给救援者说明成本，留一页给其他人提出不同意见。能重新行动只是修复的起点；之后的关系，还要看实际履约、后续伤害和彼此是否保有选择。
