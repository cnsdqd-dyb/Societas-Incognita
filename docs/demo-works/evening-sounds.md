# 傍晚的声音

我想把一个傍晚写下来。并没有什么特别的事情发生：楼下的自行车经过，铃声响了两下；有人关窗，却把一小段晚风留在了窗帘里。

街角卖花的人开始收摊。他把最后一支花送给路过的孩子，孩子拿着它跑了一小段，又忽然停住，好像怕跑得太快，花会来不及看清这个世界。

一只狗认真地闻着墙根。主人已经走出三步，狗还停在原地。他等了一会儿，也蹲下来，不知道究竟是在看狗，还是在借它的耐心看一点自己平时略过的东西。

远处传来一段口哨，不完整，吹到第三句就断了。过了几秒，又从头开始。那个人应该并不急着成为一个好口哨手，他只是想让回家的路有个伴。

我也沿着同一条路往回走。鞋底偶尔碰到一粒小石子，发出轻轻的一声。天还没完全暗下来，店门上的灯先亮了，好像总有人提前替夜晚铺好一小块地方。

如果明天还从这里经过，我也许会忘记今天的许多事情。但我希望还记得那只狗、那段吹错的口哨，以及一个孩子为了让花看清街道而忽然放慢的脚步。这些都很小，小到刚好可以带在身边。
